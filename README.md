# vaeXRD
Electronic resources of the paper "Variational autoencoders for generating multiphase powder diffraction patterns and their quantification".

To access the dataset used to trained the VAE models, please visit: https://bit.ly/4iivld8. There, you will find the files xset_macro.npy, xset_0250.npy, xset_0100.npy, and xset_0050.npy. These files correspond to the diffraction patterns modeled under different conditions of crystal sizes (data augmentation). The CIF number of the patterns in the files xset_{size}.npy are in their corresponding dfset_{size}.csv file. There are also two supporting files, dftraval.csv and dftest.csv, which contain the CIF list used for the training and test sets, respectively.
